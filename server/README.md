# pomopet-sync

Pomopet 친구 연동 서버. Cloudflare Workers + D1 위에서 돌아갑니다.

계정 개념이 없습니다. 앱이 처음 켜질 때 익명 사용자를 만들고 6자리 코드를 받습니다. 친구끼리 그 코드를
주고받으면 연결되고, 그때부터 서로의 오늘 진행 상황과 펫이 보입니다. 이메일도 비밀번호도 소셜 로그인도
쓰지 않습니다.

## 무엇이 오가나

**친구 연동을 켜기 전에는 이 서버로 아무것도 가지 않습니다.** 앱은 기본으로 꺼져 있고,
사용자가 직접 켜야 익명 계정이 만들어집니다.

올라가는 값은 집계된 숫자뿐입니다.

| 항목 | 예 |
|---|---|
| 이름 | 표시용, 사용자가 직접 입력 |
| 오늘 세션 수 / 집중 시간 / 목표 | `3`, `75`, `5` |
| 펫이 깨어났는지 | `true` |
| 연속일 | `12` |
| 지금 뭐 하는 중인지 | `focusing` |
| 펫 그림 | 26×26 PNG, 바뀔 때만 |

### 보내지 않는 것

- 이메일·비밀번호·소셜 계정 (애초에 계정 개념이 없습니다)
- 몇 시에 무엇을 했는지 같은 시각별 기록
- 어떤 앱을 켰는지 (작업 시작 감지는 전부 맥 안에서만 돌아갑니다)
- 원본 IP 주소 — 가입 도배를 세는 데만 쓰고, 그마저도 해시로 바꿔 하루 뒤 지웁니다

펫 그림은 평소엔 해시만 주고받고, 해시가 달라졌을 때만 실제 그림을 한 번 받아옵니다.

### 서버가 털리면 어떻게 되나

새어나갈 수 있는 건 위 표의 값들입니다 — 이름, 집중 시간, 스트릭, 26x26 그림.
비밀번호도 이메일도 없으니 다른 서비스로 번질 게 없고, secret 은 해시로만 저장합니다.

**앱이 이 서버에서 받는 건 숫자와 PNG 한 장뿐입니다.** 코드를 받아 실행하는 경로가 없어서,
서버가 완전히 장악당해도 사용자 맥에서 뭔가를 실행시킬 수는 없습니다. 최악의 경우는
"친구 목록에 엉뚱한 숫자가 보인다" 입니다.

## 이미 운영 중인 서버 갱신

`migrations/` 아래 파일을 순서대로 적용하면 됩니다.

```bash
npm run db:migrate    # migrations/0001_privacy_and_limits.sql
```

## 직접 띄우기

Cloudflare 계정만 있으면 됩니다. 무료 플랜이고 카드 등록도 필요 없습니다.

```bash
cd server
npm install

npx wrangler login          # 브라우저가 열립니다
npm run db:create           # 출력된 database_id 를 wrangler.toml 에 붙여넣으세요
npm run db:remote           # 운영 DB 에 스키마 적용
npm run deploy              # https://pomopet-sync.<서브도메인>.workers.dev
```

배포된 주소를 앱 설정에 넣으면 됩니다. 남의 서버를 믿기 싫으면 이렇게 각자 띄워 쓰면 됩니다.

## 로컬에서 굴려보기

```bash
npm run db:local            # 로컬 DB 에 스키마 적용 (최초 1회)
npm run dev                 # http://127.0.0.1:8787
npm test                    # 다른 터미널에서 — 두 사용자를 만들어 전 과정 확인
```

## API

인증은 `Authorization: Bearer <secret>` 하나뿐입니다. secret 은 가입할 때 한 번만 내려주고, 서버에는
해시만 남습니다. 앱은 이걸 Keychain 에 보관합니다.

| | | |
|---|---|---|
| `POST` | `/v1/register` | 익명 가입 → `{ userId, code, secret }` |
| `GET` | `/v1/me` | 내 코드·이름 |
| `POST` | `/v1/heartbeat` | 내 상태 올리고 친구들 상태 받아오기 |
| `POST` | `/v1/friends` | `{ code }` 로 연결 (양방향) |
| `DELETE` | `/v1/friends/:code` | 끊기 (양방향) |
| `PUT` | `/v1/pet` | 내 펫 그림 올리기 |
| `GET` | `/v1/pet/:code` | 친구 펫 그림 받기 |
| `POST` | `/v1/nudge` | `{ code }` 친구 쿡 찌르기 |
| `POST` | `/v1/code/rotate` | 내 코드 새로 받기 (친구 관계는 유지) |
| `DELETE` | `/v1/me` | 탈퇴 — 계정·친구 관계·찌르기 전부 삭제 |

`heartbeat` 하나가 올리기와 받아오기를 겸합니다. 앱은 세션이 끝났을 때와 주기적으로 이것만 부르면 됩니다.

```jsonc
// POST /v1/heartbeat
{ "name": "경석", "dayKey": 20260730, "sessions": 3, "minutes": 75,
  "goal": 5, "activated": true, "streak": 12, "phase": "focusing" }

// ← 응답
{ "me": { ... },
  "friends": [
    { "code": "F92VTN", "name": "친구", "dayKey": 20260730, "sessions": 1,
      "minutes": 25, "goal": 3, "activated": false, "streak": 0,
      "phase": "focusing", "petHash": "abc123", "updatedAt": 1785000000000 }
  ],
  "nudges": [ { "from": "S8VE5E", "name": "친구", "at": 1785000000000 } ],
  "serverTime": 1785000000000 }
```

## 쿡 찌르기

애플 푸시(APNs)는 유료 개발자 계정이 있어야 해서 쓰지 않습니다. 대신 찌른 기록을 쌓아두고 상대 앱이
heartbeat 할 때 받아가게 했습니다. Pomopet 은 메뉴바에 늘 떠 있는 앱이라 보통 1분 안에 전달됩니다.

- 친구인 사람만 찌를 수 있습니다
- 같은 친구는 **10분에 한 번, 하루 5번**까지
- 한 번 받아간 찌르기는 다시 오지 않습니다
- 2시간 넘게 못 받아간 것은 버립니다 (맥을 꺼놨다가 다음날 켰을 때 어제 것이 쏟아지지 않도록)

## 한도

무료 플랜은 하루 10만 요청, D1 은 하루 500만 행 읽기입니다. 앱이 1분마다 heartbeat 를 보낸다고 하면
사용자 한 명이 하루 최대 1,440 요청이니 **60~70명**까지 무료 범위입니다. 주기를 5분으로 늘리거나
앱이 유휴일 때 쉬게 하면 수백 명까지 늘어납니다.

## 서버가 죽으면

친구 목록만 비고 앱 본체는 그대로 돌아갑니다. 타이머·스트릭·펫·기록은 전부 각자 맥의 SwiftData 에
저장되고, 이 서버는 서로 보여주기용 거울일 뿐입니다.

## 휴면 계정 정리

하루 한 번(UTC 04:00 = 한국 13:00) 버려진 계정을 지웁니다. 용량 때문이 아닙니다 — D1 무료 한도는
넉넉해요. 가입만 해놓고 버린 계정이 쌓이는 걸 막는 게 목적입니다.

| 상태 | 기준 |
|---|---|
| 가입만 하고 한 번도 안 켠 계정 | 7일 |
| 켜봤지만 친구가 없는 계정 | 90일 |
| 친구가 있는 계정 | 365일 |

실사용자를 잘못 지우면 그 사람은 친구를 전부 다시 추가해야 하는데, 연락할 수단이 없어 미리 알릴 수도
없습니다. 그래서 버려진 게 확실한 것일수록 짧게, 실제로 쓰이는 것일수록 길게 잡았습니다.

## 안전장치

- 코드는 헷갈리는 글자(`0` `1` `I` `L` `O`)를 뺀 31자에서 6자리 — 8.9억 가지
- **없는 코드를 한 시간에 10번 넘게 찍으면 친구 추가가 막힘** (코드 훑기 차단).
  실패한 시도만 세므로 오타 몇 번으로는 걸리지 않습니다
- secret 은 해시로만 저장, 응답에 절대 포함하지 않음
- **가입 IP 는 해시로만 저장하고 하루 뒤 지움**. 해시에 쓰는 소금은 첫 가입 때 무작위로 만들어져
  그 DB 안에만 있으므로, 직접 띄운 서버마다 값이 다르고 해시에서 IP 를 되짚을 수 없습니다
- 친구가 아니면 남의 펫·상태를 볼 수 없음
- 세션 수·시간·목표는 서버에서 상한을 걸어 이상한 값이 들어와도 잘라냄
- 펫 그림 24KB 초과 거절, 친구 50명 상한
- 가입은 인증 없이 열린 유일한 창구라 같은 IP 에서 시간당 10개까지만 허용
- 코드가 엉뚱한 곳에 퍼졌으면 `/v1/code/rotate` 로 새로 받으면 됩니다 (친구는 그대로)
- 탈퇴하면 남의 친구 목록에서도 즉시 사라집니다
